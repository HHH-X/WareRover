## 关键上下文

SimulationContext (self.ctx) 包含以下可用组件:
- self.ctx.env: Env — 环境对象，提供 get_env_info() 和 get_walkable_neighbors()
- self.ctx.agv_manager: AGVManager — AGV 管理器
- self.ctx.order_manager: OrderManager — 订单管理器，提供 get_unprocessed_orders()
- self.ctx.grid_map: GridMap — 地图对象，提供 get_boxes_by_goods(), get_box_position(), get_receiver_position() 等
- self.ctx.fault_manager: FaultManager — 故障管理器
- self.ctx.system_config: SystemConfig — 系统配置
- self.ctx.logger: GlobalLogger — 日志记录器

env.get_env_info() 返回字典包含:
- 'action_queues': Dict[int, List[Tuple[int,int]]] — 各AGV当前路径队列
- 'current_grid_pos': Dict[int, Tuple[int,int]] — 各AGV当前位置
- 'agv_sizes': Dict[int, int] — 各AGV的尺寸
- 'carrying_status': Dict[int, bool] — 各AGV是否正在搬运

OrderManager:
- get_unprocessed_orders() -> List[Order] — 获取待处理订单
- mark_order_as_processing(order_id, agv_id) — 标记订单为处理中

Order 对象属性: order_id, goods_id, receiver_id, required_size, box_id

AGVManager:
- get_agv_size(agv_id) -> int — 获取AGV尺寸

GridMap:
- get_boxes_by_goods(goods_id) -> List[int] — 获取存有某商品的货架ID列表
- get_box_position(box_id) -> Tuple[int,int] — 获取货架位置
- get_receiver_position(receiver_id) -> Tuple[int,int] — 获取收货台位置
- get_wait_zone_position(agv_id) -> Tuple[int,int] — 获取等待区位置

AGVAction 枚举: PICK, HANDOVER, PLACE
